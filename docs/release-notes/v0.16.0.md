# ArenaDesktop v0.16.0

## Settings search and backup improvements

Settings search now finds individual controls as well as sections. Use Down and Up to browse matching controls and Enter to move focus to the selected result. Search results are announced through the accessibility live region.

The Account profiles section can export or restore one profile's preferences without changing the target profile's sign-in or identity. The export contains the profile name, start page, downloads-folder choice, color, zoom and data cap; it does not contain cookies or site data. Export offers password encryption; if you choose plain JSON, the profile name, custom start page and local folder choices are readable by anyone who opens the file. For a manual site-data copy, the profile-folder button opens the relevant WebView2 directory. Exit ArenaDesktop fully before copying or restoring files. Windows-protected sign-in cookies usually only work for the same Windows user on the same PC.

Restoring a settings backup now shows changed areas and profile names before loading it into the Settings draft. Cancel leaves the draft alone; OK in Settings is still required to save.

## Accessibility and verification

Settings and Shortcuts expose clearer accessible names and live result announcements, and tab navigation is explicitly continuous. Automated tests pin these declarations and keyboard-search wiring. This is not a substitute for an on-machine accessibility pass: Narrator, keyboard-only use, text scaling, Light theme, Windows High Contrast, and the new Settings screenshots remain **Unverified** until someone performs the v0.16.0 checklist on a real Windows desktop.
