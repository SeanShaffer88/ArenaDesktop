# ArenaDesktop v0.15.0

## Settings window restyle

The Settings window is easier to scan and use: its nine sections are grouped into cards, section titles are white with a short red accent rule, and the fields and buttons use the shell's shared theme colors. The OK and Cancel buttons remain fixed at the bottom while you scroll. The default window width is now 580 pixels so the widest setting row fits in its card. A window whose size was already saved keeps that size.

The search filter still hides whole sections, and a settings-load failure still appears in the banner above the sections. No settings or control behavior was intentionally changed.

## Verification status

The XAML, Release build, and full Core test suite are verified in CI. The appearance and behavior of the window on Windows—including Light theme and Windows High Contrast—remain unverified on a real Windows desktop; see the v0.15.0 item in `RELEASE_CHECKLIST.md`.
